Summary: Smart Chatwork does not collect, transmit, sell, or share any of your data. Everything the extension stores stays inside your own browser. The extension makes no network requests to any server of its own — it has none.

1. What this extension does

Smart Chatwork is an independent, third-party browser extension that adds productivity features (a one-tap template bar, @‑mention suggestions with automatic romaji, slash templates, and a related-messages quick view) to the Chatwork web app at https://www.chatwork.com. It runs only on that site.

2. Data the extension stores — locally only

To provide its features, the extension keeps the following data in your browser's local extension storage (chrome.storage.local) and page-local storage (localStorage). This data never leaves your device:

DataPurpose
Your settings (feature toggles, language, honorific suffix)Remember your preferences
Templates, groups, and romaji readings you createProvide the template and mention features
Member names / Chatwork IDs / avatar URLs of rooms you open (learned list)Populate the group-member picker in the settings popup
Recently mentioned members and template usage countsRank frequently used items first

3. Data the extension reads

While you use Chatwork, the extension reads — in memory, on your device only — the room member list, loaded timeline messages, and your account name that the Chatwork web app itself has already loaded, in order to render mention suggestions, template variables, and the related-messages view. It does not read your Chatwork password, API tokens, or cookies.

When you click the preview (👁) button on a file attachment, the extension downloads that one file from Chatwork's own servers — the same file the Chatwork "download" link would give you, using the Chatwork session you are already signed in to — and parses it entirely in your browser to render the preview (Markdown, Excel, Word, PowerPoint). The file's contents are processed in memory on your device and are never sent to the developer or any third party.

4. Data collection and sharing: none

  • No data is transmitted off your device by this extension.
  • No analytics, tracking, advertising, or fingerprinting.
  • No data is sold or shared with third parties.
  • No remote code is loaded or executed.

5. Permissions

The extension requests a single permission, storage, used to save your settings and templates locally. Its content scripts run only on https://www.chatwork.com/*.

6. Data removal

Uninstalling the extension removes all data it stored. You can also clear individual items from the settings popup at any time.
